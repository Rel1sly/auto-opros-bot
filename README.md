# Авто-помощник опроса (шкала 1–10, рандом 4–5–6–7)

![GUI](screenshot.png)

Автокликер для психологического тестирования (130 вопросов, шкала 1–10).
Без слежения за таймером — работает по фиксированным паузам по кругу.

## Как работает
- Авто-поиск ряда кружков 1–10 (OpenCV HoughCircles), вычисляет 4/5/6/7
- Авто-поиск зеленой кнопки **Ответить**
- Цикл: ждать `wait_before` (5 сек) → рандом 4/5/6/7 → клик по цифре → клик **Ответить** → ждать `wait_after` (6 сек) → снова
- Мышь почти моментальная (0.08 сек, `0` = мгновенно)
- `F7` — выключить везде, `F6` — включить

## Запуск
```bat
pip install -r requirements.txt
python auto_otvet.py
```
Или двойной клик по `run.bat`.

1. Открой тест в браузере на весь экран, масштаб 100%.
2. Нажми **НАЙТИ АВТОМАТИЧЕСКИ**.
3. Проверь кнопками **Проверить поиск Ответить** / **Тест клика Ответить**.
4. Жми **ВКЛЮЧИТЬ (АВТО)**. Выключение — `F7`.

## Настройки
- Рандом 4-5-6-7 или только 5, галки пула, анти-повтор
- Клик по цифре вкл/выкл, клик Ответить вкл/выкл
- Пауза ДО (5 сек), ПОСЛЕ (6 сек), скорость мыши
- Ручная калибровка — запасной вариант, если авто не нашло
